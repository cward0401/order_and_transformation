# Week 2 – Dynamic Systems Representations

## Overview

This module explores foundational representations of dynamic systems using structured, time-evolving models. The focus is on understanding how systems evolve over time and how state transitions can be expressed clearly in code.

---

## Objectives

- Represent systems as evolving state processes  
- Understand time-indexed transformations  
- Build deterministic update rules  
- Develop clean simulation structure  

---

## Core Concepts

- Discrete-time systems  
- State evolution  
- Deterministic transitions  
- Local vs global structure  

---

## Notes

This week establishes the foundation for more complex modeling. The emphasis is on clarity, correctness, and structured thinking about system evolution.
